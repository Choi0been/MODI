# MODI

**운전할 때는 운전에, 쉴 때는 휴식에 집중할 수 있도록.**

MODI는 사용자의 선호 설정과 차량 이용 상황에 맞춰 공조와 실내 장치를 자동으로 조절하는 **Pleos 기반 차량 애플리케이션**입니다. 팀 **iRO**는 반복적인 스크린 조작을 줄이고, 사용자가 원하는 쾌적한 실내 환경을 제공하는 서비스를 개발합니다.

## 기획 배경

최근 차량 실내 디자인은 물리 버튼을 줄이고 스크린 안에서 다양한 기능을 조작하는 방향으로 변화하고 있습니다. 공조 기능 역시 스크린으로 통합되면서, 운전 중 원하는 설정을 찾아 변경하는 일이 번거로워지는 경우가 많습니다.

이러한 불편함 때문에 운전자는 온도 조절을 자동 모드에 맡기거나, 악취가 심한 구간을 지나면서도 내기 순환 모드로 전환하지 않고 참는 등 공조 조작을 피하기도 합니다.

MODI는 **사용자가 상황에 따라 조절하고 싶은 설정을 미리 저장하고, 필요한 순간에 사용자를 대신해 실행하는 서비스**를 지향합니다. 탑승부터 하차 전까지 공조와 실내 장치를 이용하는 과정에서 반복적인 조작을 줄여, 운전과 휴식에 집중할 수 있도록 돕습니다.

## 주요 기능 및 차량 특화 요소

아래 기능은 MODI가 구현하고자 하는 주요 서비스 동작입니다.

### 1. 주행 환경에 따른 실내 공기 관리

- 사용자가 저장한 악취 구역을 지날 때 내기 순환 모드로 자동 전환합니다.
- 터널 내부 등 공기질이 나쁜 환경에서는 공기 청정 기능을 자동으로 가동합니다.
- 주행 위치와 환경에 맞춰 공조 기능을 제어하여 쾌적한 실내를 유지합니다.

### 2. 휴식 상황에 맞춘 공조·시트 설정

- 휴게소에서 P단을 체결하거나 회사 주차장에서 점심시간에 탑승하는 등, 운행 없이 휴식하려는 상황에서 사용자에게 휴식 여부를 확인합니다.
- 사용자가 휴식을 선택하면 미리 저장한 편안한 온도와 취침용 시트 포지션으로 전환합니다.
- 휴식이 끝나면 기존에 설정한 운전용 시트 포지션과 공조 설정으로 복구합니다.

### 3. 계절에 따른 초기 냉난방 보조

- **겨울:** 히터가 충분히 따뜻해지기 전까지 시트 열선을 작동시켜 추위를 덜 느끼도록 돕습니다.
- **여름:** 실내 온도를 빠르게 낮추기 위해 일시적으로 에어컨을 최대 세기로 가동합니다.
- 여름철 집중 냉방으로 목표 온도에 도달하면 사용자가 기존에 설정한 온도와 풍량으로 복구합니다.

## 주요 사용 시나리오

MODI는 Pleos가 탑재된 차량을 운행하는 모든 운전자를 대상으로 합니다. 차량에 탑승한 순간부터 내리기 전까지, 사용자의 의도와 상황에 맞춰 공조를 비롯한 실내 장치를 자동으로 조절하는 것을 목표로 합니다.

| 상황 | MODI의 동작 | 사용자 경험 |
| --- | --- | --- |
| 저장한 악취 구역을 통과할 때 | 내기 순환 모드로 전환 | 공조 메뉴를 직접 조작하는 부담 감소 |
| 터널 등 공기질이 나쁜 환경을 지날 때 | 공기 청정 기능 가동 | 쾌적한 실내 환경 유지 |
| 휴게소에 정차하고 P단을 체결했을 때 | 휴식 여부 확인 후 저장된 공조·시트 설정 적용 | 휴식 준비를 위한 반복 조작 감소 |
| 점심시간에 회사 주차장 차량에서 쉴 때 | 휴식 여부 확인 후 편안한 온도와 시트 포지션으로 전환 | 원하는 환경에서 휴식에 집중 |
| 휴식을 마치고 운전을 준비할 때 | 기존 운전용 시트 포지션과 공조 설정 복구 | 익숙한 운전 환경으로 복귀 |
| 추운 겨울에 탑승했을 때 | 히터가 따뜻해지기 전 시트 열선 작동 | 난방을 기다리는 동안 추위 완화 |
| 더운 여름에 탑승했을 때 | 최대 세기로 냉방 후 목표 온도 도달 시 기존 설정 복구 | 빠른 냉방과 선호 설정 유지 |

## 기대 효과

- **조작 부담 감소:** 상황마다 스크린에서 공조 메뉴를 찾아 조절하는 과정을 줄입니다.
- **운전과 휴식에 집중:** 운전 중에는 주행에, 정차 후에는 휴식에 집중할 수 있도록 돕습니다.
- **개인화된 실내 환경:** 사용자가 저장한 설정을 바탕으로 선호하는 온도와 시트 포지션을 제공합니다.
- **상황에 맞는 자동 제어:** 주행 환경, 휴식 여부, 계절에 따라 필요한 실내 장치를 조절합니다.
